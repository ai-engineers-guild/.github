# Code of Conduct

This community follows the principles of ODS (Open Data Science):

- Transparency in all decisions
- Horizontal connections - no hierarchy by default
- Peer verification - contributions are reviewed by the community
- Contribution over seniority
- Results over rhetoric

For detailed rules see [main_rules.md](https://github.com/ai-engineers-guild/ai-engineers-guild-rules/blob/master/main_rules.md) in the rules repository.
