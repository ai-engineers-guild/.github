# Contributing to AI Engineers Guild

We welcome contributions from everyone. Here's how to get started:

## Branching strategy

- `master` - stable, protected. Requires PR + review from core team.
- `dev` - active development. Submit your PRs here. Open to all.

## Steps

1. Fork the repository
2. Create a branch from `dev`
3. Make your changes
4. Submit a PR to `dev`
5. After community discussion, changes are merged into `master`
